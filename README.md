# SortMania
SortMania is a feature-packed Sort Visualizer with features like:

Comparison - Compare 2 Sorting Algorithms head to head!

Benchmark - Run all 40 sorting algorithms at the same time and rank them by how fast. (in Ms)

Yes you heard that right, there are 40 sorting algorithms to be used.

And you can create your custom algorithms and a save and load feature!
