Guide
How to code algorithms JavaScript

1. On the Sortmania screen open Custom Algorithm, type or paste your code, then press Run custom.

2. Write one async function named main (or type your own name in Entry point). It receives elements, the array of pieces. Sort that array in place and return nothing.

3. Use the same helpers as SortVisualizer.com:

getValue(el)The number on a piece. Pass the piece or its index.await swap(i, j)Swaps two pieces by index and draws it.await updateBox(elements, i1, i2, i3)Redraws after you changed the array yourself. The indexes are highlighted.

The pieces are the numbers 1 to n in random order, and n is at most 20,000. It is plain JavaScript: no DOM and no imports, but you can write your own helper functions. One-line code works too.

async function main(elements){
  const n=elements.length;
  for(let i=0;i<n-1;i++){
    for(let j=0;j<n-1-i;j++){
      if(getValue(elements[j])>getValue(elements[j+1])){
        [elements[j],elements[j+1]]=[elements[j+1],elements[j]];
        await updateBox(elements,j,j+1);
      }
    }
  }
}

Tips

Save your sort with a name in the Custom window, and load it later. Saved sorts show up under Custom in Algorithms and in the Compare dropdowns, so you can race them against the built-in sorts.

Code pasted from a chat is cleaned up for you (code fences, curly quotes, hidden characters). If something is wrong, the error shows in the Custom window. If your function ends with the array not sorted, you get a message instead of a result.

Stats for custom sorts count reads and writes. Compares are not counted, because the app cannot see inside your code.

APIs JavaScript

Your code is plain JavaScript. The entry point (default main) must be an async function that takes one argument, the array of elements. Sort that array in place and return nothing. You can declare other functions and classes. No imports.

getValue(el)The number value of an element, given the element or its index. await updateBox(elements, i1, i2, i3)Call after you change the array. The indexes are the pieces to highlight. await swap(i, j)Swaps two pieces by index. No updateBox needed after.

These match the APIs on SortVisualizer.com. Values are the numbers 1 to n in random order. Reads (getValue) and array changes are counted; compares are not. Array methods such as elements.sort work too.
